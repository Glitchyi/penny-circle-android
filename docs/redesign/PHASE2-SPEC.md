# PACKAGE A: building blocks (owner: agent A). Create exactly these 4 NEW files; edit nothing else.

1. RollingAmount.kt: an odometer. Format `rupees` with Indian grouping: `java.text.NumberFormat.getIntegerInstance(java.util.Locale("en", "IN")).format(rupees)` (gives 12,34,567). Render each character in a `Row(verticalAlignment = Alignment.Top)`. Each DIGIT is wrapped in `AnimatedContent(targetState = digitChar, transitionSpec = { (slideInVertically(spring(dampingRatio = 0.75f, stiffness = 300f)) { it } + fadeIn(tween(200))) togetherWith (slideOutVertically(tween(260)) { -it } + fadeOut(tween(200))) }, label = "digit") { Text(it.toString(), style = style, color = color) }`. For a value that is increasing the digits slide up (as above); when the new digit is smaller than the old one, slide down instead (invert the signs). Commas are plain `Text`. When `LocalReducedMotion.current` is true use `EnterTransition.None togetherWith ExitTransition.None`. Do not animate on first composition (AnimatedContent already starts at the initial value). Key the digits by position from the RIGHT so adding a digit does not re-animate the others: build the list of chars reversed, render with `key(index)`, then reverse for display (a simple approach: `val chars = text.reversed()` and render `chars.indices.reversed().forEach { i -> key(i) { ... } }`). Semantics: `Modifier.semantics(mergeDescendants = true) { contentDescription = "₹$formatted" }` on the Row and `clearAndSetSemantics` on children so TalkBack reads the amount once.
2. HorizonArc.kt: a `Canvas` (default height 84.dp via `Modifier.height(84.dp).fillMaxWidth()` applied BEFORE the caller's modifier is combined: `modifier.fillMaxWidth().height(84.dp)`) that draws a wide shallow arch: an elliptical arc path whose top touches y = 1.dp, spanning the full width (the arc's endpoints at the bottom-left and bottom-right corners). Stroke the arch outline 1.dp in `color.copy(alpha = 0.75f)`; fill the area under it with `Brush.radialGradient(colors = listOf(color.copy(alpha = 0.10f + 0.25f * intensity), Color.Transparent), center = Offset(size.width / 2, 0f), radius = size.width * 0.6f)`; and draw a soft glow above the line: a second radial gradient centred on the arc's top with `color.copy(alpha = 0.20f * (0.5f + intensity))`, radius 120.dp, clipped to nothing (just draw it). `intensity` is coerced to 0f..1f. Animate `intensity` with `animateFloatAsState(tween(900))` (snap when `LocalReducedMotion.current`).
3. HardShadowButton.kt: a pressable button with a hard offset shadow. Structure: `val pressed by interactionSource.collectIsPressedAsState()`; `val off by animateDpAsState(if (pressed) shadowOffset else 0.dp, spring(dampingRatio = 0.6f, stiffness = 600f))` (snap when reduced motion). `Box(modifier.padding(end = shadowOffset, bottom = shadowOffset)) { Box(Modifier.matchParentSize().offset(shadowOffset, shadowOffset).background(shadowColor, shape)); Surface(onClick = onClick, enabled = enabled, shape = shape, color = containerColor, contentColor = contentColor, interactionSource = interactionSource, modifier = Modifier.offset(off, off).defaultMinSize(minHeight = 52.dp)) { Row(Modifier.padding(horizontal = 20.dp, vertical = 12.dp).fillMaxWidth(), horizontalArrangement = Arrangement.Center, verticalAlignment = Alignment.CenterVertically, content = content) } }`. Note that `matchParentSize` makes the shadow the size of the Surface + padding area; adjust so the shadow box has exactly the Surface's size and sits offset by `shadowOffset` (for example put the Surface in an inner Box and size the shadow with `Modifier.matchParentSize()` of that inner Box). Haptic: on press-down start fire `LocalView.current.performHapticFeedback(android.view.HapticFeedbackConstants.KEYBOARD_TAP)` once per press (use `LaunchedEffect(pressed) { if (pressed) ... }`).
4. DottedCanvas.kt: `fun Modifier.dottedCanvas(glow: Boolean = true): Modifier = composed { ... }` that reads `LocalPennyTokens.current` and draws behind the content with `drawWithCache`: a grid of tiny dots every 22.dp (dot radius 0.7.dp) in `tokens.text.copy(alpha = if (tokens.dark) 0.07f else 0.07f)`, and when `glow` is true a radial gradient glow at the top centre in `tokens.accent.copy(alpha = if (tokens.dark) 0.22f else 0.14f)` radius = 70% of the width, fading to transparent. Cache the dot positions loop inside `onDrawBehind`. (`composed` and `Modifier.drawWithCache` are fine in this project.)
